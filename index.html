About Kfes Defender

Kfes Defender Installer

The Installer uses PyInstaller for building. However, it installs even if you don't have PyInstaller downloaded. It automatically assembles the necessary components embedded in the installer. The installer includes 2 programs at once: Kfes Defender and KDUI Compiler.

During installation, it uses the pip package manager, which is already built into Python, to download and install the necessary components.

Update to v1.4.3

Version 1.4.3 is the latest version. If you encounter an error after updating, don't panic. This error simply means the antivirus process could not be restarted automatically. Just launch the antivirus manually to see the updated version.

How to install the update:

  1. Open the antivirus and go to Settings.
  2. At the very bottom, select the About & Updates tab.
  3. In the bottom right corner, you will see the Open File button. Click it.
  4. Select the .kdui file to update the program.
  5. Then click Install and Restart.
If something is wrong with the antivirus, click "Return to built-in version" in the "About & Updates" tab.

Kfes Defender (Antivirus)

The main antivirus program designed to protect your system.

Important Note: Due to the early versions of the program, the antivirus may work incorrectly or have bugs. We are actively working on improvements.

KDUI Compiler

This program uses a simple Tkinter interface. It uses index.html and main.py from a ZIP archive and compiles everything into a .kdui format (Kfes Defender Update Image).
